A program that writes a one-star review of Monday, written as if Monday were a restaurant, to `/output/entry.txt` — for make.fun's "One Star for Monday" bounty. Python 3.13, standard library only, deterministic.

> One star. Monday served my weekend cold, lost my reservation, and billed me for the week. I asked for the manager; also Monday.

## Run it

```sh
python3 main.py
```
